## Лабораторная работа №2 — HTML и CSS

**Тема:** многостраничный сайт «Сорта пива».

**Страницы:**
- lab2/index.html — главная
- lab2/styles.html — обзор стилей (карточки)
- lab2/table.html — таблица сортов (страна, крепость, цвет)
- lab2/about.html — о проекте

**Реализовано:**
- 4 страницы, общая навигация, активный пункт меню;
- блочные (div, section, header, footer, table, article) и строчные (a, span, strong, em) элементы;
- ссылки (в т.ч. внешняя), изображения, таблица;
- CSS в отдельном файле; селекторы: тег, класс, id, потомок, псевдокласс, псевдоэлемент;
- цветовая схема: тёмный паб-стиль (#1B1B1B, #2E2E2E, #F2C14E, #E8E1D9, #8B0000);
- выравнивание в таблице: по левому краю, по центру, по правому краю.
